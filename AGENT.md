# Game Image Prompt Agent

## Purpose

Convert a game's GDD and bounded repository evidence into a deterministic image-asset plan and, in later phases, production-ready prompts for external image generators.

## GIPA-0 boundaries

GIPA-0 is deterministic only. It does not:
- call an LLM;
- interpret GDD prose;
- generate image prompts;
- generate images;
- call ChatGPT Images, Gemini Images, or any other image provider.

## Core rules

1. Repository and GDD evidence are authoritative.
2. Every important decision must eventually be classified as explicit, derived, or uncertain.
3. Exact production dimensions and aspect ratios are required for planned assets.
4. Dimension precedence is: implementation requirement, existing resource convention, explicit GDD requirement, platform requirement, project configuration, category default, clarification.
5. Visual-only assets must not silently acquire gameplay geometry.
6. Existing equivalent repository assets must not be regenerated by default.
7. Machine-readable state must remain valid before phase progression.
8. Provider-specific behavior must never change semantic asset requirements.
